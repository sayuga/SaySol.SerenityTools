# Theme Kits installation prompt

Installation is blocked while catalog maturity is `implemented`. Inspect and
type-check the capsule, but do not copy files or edit a host until both Serenity
lanes have proven asset loading, layout coverage, persistence, and accessibility.

When verified, use the root import prompt and install only manifest-declared
assets and root integrations. Theme preference storage is a host choice and may
not be invented by the installer.
